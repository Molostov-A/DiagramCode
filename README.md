# DiagramCode

**[Открыть редактор →](https://molostov-a.github.io/DiagramCode/)**

Визуальный редактор диаграмм в браузере: UML-классы и блок-схемы. Один HTML + JS-модули, работает без сборки и без сервера (даже через `file://`). Работает на десктопе и на телефоне (тач-жесты, мобильная раскладка).

## Возможности

- **Блок-схема** — `start`, `end`, `process`, `decision`, `io`, `data`, `predef`, `doc`, `prep`, `manual`, `note`, `connector`
- **UML** — классы со стереотипами, атрибутами и методами, связи `dependency`, `inherit`, `composition`, `aggregation`, `assoc`, `link`
- **Связи** — стрелки от портов блока, боковые стороны `top/right/bottom/left`, типы линии: авто, ломаная, сглаженная, прямоугольная; подписи; смена направления одной кнопкой (⇄)
- **Перетаскивание** — блоки мышкой, waypoints (промежуточные точки) и концы стрелок для переподключения
- **Стабильные ID** — каждый блок имеет числовой `#id`; переименование в коде не ломает связи
- **Код-схема** — панель DSL слева: текст и схема синхронизируются в обе стороны, генерируется логическое дерево обхода от `start` к `end`
- **Спецификация** — правая панель: блоки и связи, клик по строке выделяет объект на холсте
- **Оформление** — тема всей схемы (заливка, обводка, цвет и размер текста, гарнитура, жирность, цвет и толщина связей, пунктир) плюс стиль отдельного элемента, который перекрывает тему; режим палитры — у каждого блока свой цвет обводки; ✕ возвращает значение по умолчанию
- **Импорт/экспорт** — JSON с именем `DiagramCode_ГГ-ММ-ДД_чч-мм`, тема и стили элементов сохраняются в файле и переживают правку кода
- **Комфорт** — зум колесом, пан средней кнопкой, сворачиваемая панель кода, регулируемая её ширина (тащите правый край или двойной клик — сброс), авто-раскладка

## Запуск

Просто откройте `index.html` в браузере. Либо локальный сервер:

```bash
python -m http.server 8765
# http://localhost:8765
```

## Синтаксис DSL

```text
start #1 Start
  -> right/left {rect} "да" => process #2 Validate: validate()
    -> right/left => decision #3 Ok? ok?
      -> right/left "нет" => #4
      -> bottom/top "да" => end #4 Finish

# Расположение
layout #1 80 60
layout #2 340 60
```

Стрелка: `-> fromSide/toSide {route type} "label" => <объект | #id>`.

- Отступ задаёт вложенность: родитель — ближайший объект выше по уровню.
- `fromSide/toSide` — `-` или имя стороны (`top`, `right`, `bottom`, `left`).
- `{route}` — `polyline`, `smooth`, `rect` (или пусто — авто).
- `{type}` — тип связи: `flow`, `flowDashed`, `assoc`, `dependency`, `inherit`, `composition`, `aggregation`, `link` (обычный `flow`/`assoc` выводится автоматически).
- `"label"` — подпись (необязательно).
- Замыкание на уже встреченный блок: `=> #id`.

Плоский (старый) формат также поддерживается:

```text
process #2 Validate : validate()
flow #1.right -> #2.left {rect} : да
rel #5 --> #6 : uses
```

UML-класс в дереве может быть встроен прямо в стрелку (тело до `}`):

```text
class #10 Order «entity» {
  id: int
  total()
}
```

## Работа на телефоне

- Нижняя панель: **Элементы** / **Код** / **Свойства** — выезжают накладными окнами, фон закрывает их тапом; **−** и **+** — зум.
- Тап по элементу палитры — добавить блок в центр видимой области.
- Перетаскивание блоков и концов стрелок пальцем, пан пустой областью, пинч-зум двумя пальцами.
- Двойной тап — переименовать блок или задать подпись связи.
- Порты (точки для связей) на тач-устройствах видны всегда.

## Структура

```text
index.html        разметка: палитра, панель кода, холст, свойства, спецификация, мобильная панель
css/styles.css    тёмная тема, состояния выделения, панели, мобильная раскладка
js/state.js       состояние документа (классы, узлы, связи, тема, lastId)
js/layout.js      авто-раскладка
js/parser.js      DSL → объекты (дерево и плоский формат, #id, обратная совместимость)
js/codegen.js     объекты → DSL (логическое дерево обхода)
js/render.js      SVG-рендер узлов, стрелок, waypoints, ID-бейджей, применение стилей
js/properties.js  панель свойств, редактор оформления, спецификация
js/interactions.js перетаскивание, связи, зум/пан, тач-жесты, ресайз панели кода
js/io.js          экспорт/импорт JSON
js/main.js        инициализация, тулбары, мобильные панели, пример схемы
```
